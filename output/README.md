# 派生产物边界

本目录只跟踪`CLAUDE.md`和`README.md`。
派生产物不作为构建、测试或运行时输入。
正式语言源位于`languages/`。
生成物不能覆盖已审批语言源。

## 来源与验收

每次抓取先记录目标版本、原厂摘要和会话身份。
旧版本材料不能作为新版本验收证据。
缺少来源时，标记未证；不要推断版本。
草稿、静态检查和真实显示分别记录。
构建成功不能替代运行时加载或实屏验收。

## 保存与清理

实跑证据写入仓外会话目录。
研究、日志和历史方案归档到私人文档。
公开文档只保存稳定规则和可重复步骤。
构建、测试和发布不得依赖私人文档。

清理前核对归属和当前依赖。
需要保留历史时，先归档原字节并核回远端。
再删除已核对的过期派生产物。
保留当前成功制品、原始失败和未完成测试的输入。
不要全局清空`/tmp`或修改用户安装的App。
