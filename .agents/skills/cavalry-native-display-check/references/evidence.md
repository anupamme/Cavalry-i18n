# 证据与定位

## 结果记账

沿[统一SOP](../../../../docs/acceptance-workflow.md)记账，不另建结果格式。
每项绑定总账ID、语言、候选/资源、场景、owner和实际证据。
同批可共用进程与原图；结论仍逐项绑定目标。
编译、实际加载、首个目标调用、稳定显示和首次可见帧分别记账。
截图只证明该帧；刷新后正确不能补首帧。
首帧须在任何修正动作前取得直接证据。
helper曝光工作区不证明正常启动、认证或首帧。
自动化E2E要求驱动完成动作、读回与判定；用户代操作只记人工辅助。
目标未读到记未验；导航失败不冒充译文失败。
原始失败保留；交叉通过不得改写为OCR通过。
菜单已关闭不证明业务动作完成。
截图仍是旧态时，另次观察目标后态；不重复提交动作。
只有AX文字而无对应像素时，分别记录，不授可见通过。

## 复用与重测

成功驱动连同相对依赖、构建入口、输入和预期保存。
现场结果留私人文档；不把每次失败变成全局新门。
复用前核候选、资源、语言、场景与目标是否适用。

| 变化 | 复验范围 |
| --- | --- |
| 源与制品未变，仅中断、改路径或补判据 | 续剩余动作或离线审查，不重编、不全量回放。 |
| 测试host漏某语种或驱动接线错误 | 修测试依赖，仅补该动作；不先判产品漏译。 |
| 仅Apply后启动接线改变，字体源/库未变 | 验真实Apply→启动，复用适用字体证据。 |
| 字体实现或对应二进制改变 | 回归本候选全部适用三语显示矩阵；不继承旧字体PASS。 |

资源副本内容复用核源SHA和来源，不强求路径相同。
实际App、PID与写入目标仍绑定本轮路径。
有限输入身份每轮记录一次，不扫描整棵App哈希。
受管部署分别核输入制品与签后安装槽，不要求两份摘要相等。
runtimeSourceSha256绑定输入，槽fingerprint绑定签后文件。
不加定时重绘、延迟改写或常驻诊断。
只需确认载库时，用`lsof -a -p PID -d txt -Fn`匹配实际路径。
不为载库确认生成完整内存图；工具超时不判产品失败。
已有适用原图时先离线断言；失败只补受影响项。
缓存清理不触发产品重验；保留成功源码、当前制品和原始失败。
界面工具或窗口截图失败时，先核桌面是否锁定。
锁定时停止界面输入；不据工具失败修改字体或启动器。

## 资源与时钟

先核计数单位，不从JSON键名猜单位。
libproc的CPU累计值按本机Mach timebase换算。
原始样本保留；单位修正只重算，不重跑动作。
视频PTS未校准时，不称启动到首字的耗时。
窗口元数据出现不等于文字已绘制。
AX菜单耗时包含驱动遍历，不称可见响应时延。
8秒是性能参考，不是硬性验收线；优先减少真实等待。
播放起止不齐时，取两段都在播放的同长区间。
记录原始样本行；不借单次对照作统计结论。

## 已有OCR的区域断言

```sh
python3 "$SKILL/scripts/verify_visible_text.py" \
  --ocr /path/to/session/text.json --expected '目标译文' \
  --roi LEFT TOP RIGHT BOTTOM
```

JSON含image、expected和rows；image相对JSON目录解析。
每行含text、x、y、width、height。
Vision行框用左下原点归一化坐标；ROI用PNG左上原点像素。
脚本要求单行包含目标文字且整行在ROI内，忽略空白差异。
它不证明全文相等、动作消费或字形正确，不用整窗拼接matched。
PNG边缘半像素舍入可夹回并保留原框；内部ROI不放宽。
原图来自同PID的实际CG窗口；ROI取当前布局，不取整个桌面。
补OCR只识别现有原图的失败区域，不向引擎注入预期词。
局部坐标先显式换算到全图，保留原坐标与换算式。

## 既存帮助popup全文OCR

对已有目标JSONL和popup PNG运行离线采集器：

```sh
python3 "$SKILL/scripts/audit_help_popups.py" \
  --targets /path/to/targets.jsonl \
  --ocr-tool /path/to/offline-ocr-command \
  --out /path/to/new-ocr-review
```

采集器只传PNG路径和空expected参数；批准说明只用于本地比较。
OCR命令须输出JSON对象`image`、`expected`与`rows[{text}]`；`expected`必须为空。
采集器忽略OCR工具的`matched`字段；工具路径由调用者提供，不随技能分发。
采集器保留OCR原文、目标行SHA、PID、CG窗口和图像SHA。
输出为source-snapshot、vision-commands、vision-raw、pixel-results和summary。
targets每行提供key、locale、approvedDescription、exactPid、popupReadback与captures。
说明标签只接受已观察的QLabel标题`说明： `、`說明： `或`説明: `。
采集器不搜索正文关键词来猜测标题。
空白折叠后逐字比较；正文空行截断匹配，不删标点或合并非连续行。
`OCR-EXACT`只表示绑定原图的OCR文本匹配，不证明画面字形正确。
`REVIEW-OCR-MISMATCH`要求核对原图，不直接判产品漏译。
CG窗口须与主窗不同，并匹配唯一行的边界和Qt四边三像素范围。
popupIndex须为从1开始的正整数；布尔值不是索引。
缺少唯一窗口绑定、精确标题或稳定SHA时，结果进入`REVIEW-*`。
退出码0只表示采集记录已写完，不代表界面、字体或首帧通过。

日文ロ/口等形近误识，交叉核批准文件/键、实际控件全文和该owner原PNG。
三者吻合且原图可读时可判显示通过；保留原OCR失败及交叉依据。
文件有译文不证明消费者已接通；不为误识重开App或改译文。

## 英文、方框或错字形

统一分类为“自绘文字”，字体是其绘制依赖。
清单记录显示键、原文、producer与绘制入口。
另列译文准入、实际消费、字体覆盖和实屏结果。
译文存在不证明字体具有所需字形。
目录键只能提供候选，不能证明它使用自绘。
标准Qt控件与Skia路径须由调用链区分。
同类文字可走不同owner，单位置PASS不覆盖整类。
优先扩展已证精确owner，复用已有字体回退核心。
不得为统一追踪引入全局文本拦截或用户内容扫描。

先核 exact PID、语言和该进程实际加载的库路径，再分流。
播放疑似改变文字时，同场景、同窗口采集播放前、播放中和停止后画面。
整块文字消失记为可见性差异；文字仍在但缺字才进入字形定位。
三帧只区分现象；没有源证据时不推断厂商行为或原因。

| 观察 | 下一步 |
| --- | --- |
| 模型身份、用户输入或字体名为英文 | 核原文保留规则，不改模型值。 |
| 显示键缺批准译值 | 绑定owner、角色和英语源，再补译。 |
| 译值已有，消费者仍是英语 | 查键、参数格式和接线，不重译。 |
| 文本正确，字形缺失或错误 | 核完整名称、测量与绘制字体。 |
| 原厂窗口未加载候选 | 修测试目标，不判候选失败。 |
| 面板未加载或owner不可读 | 记未验，先修导航或读取器。 |

控件全文已含U+FFFD时，先查编码和字节裁剪。
核批准资源、宿主输入长度与实际控件码点。
文本完整但字形缺失时，再进入字体分支。
数据补偿限定已证键和消费者，不改共享日志。
同文欢迎窗标题、Guide标题和底部日志分别绑定消费者。
底部日志若来自共享MessageBar，先定位原始生产者。
相同前缀不证明来自厂商；未知caller及用户日志保持原文。

回退须覆盖整串ASCII、数字与CJK，不能只修首个缺字。
CoreText命名候选用已验证的精确PostScript名。
同字体名与traits不证明glyph映射相同；非零glyph不证明字形正确。
测量与绘制须共用回退；静态接线不替代实测宽度和裁切。
字体源变更时读[injector/native/README.md](../../../../injector/native/README.md)。
私人历史用于找成功方法，不给当前候选授PASS。
