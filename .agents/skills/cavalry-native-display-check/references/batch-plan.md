# 合批方法

## 分母与范围

项目根的[CAVALRY_2_8_MIGRATION_PLAN.md](../../../../CAVALRY_2_8_MIGRATION_PLAN.md)§5.2是唯一44项主账。
A–H含调查、资源、产品事务、UI、性能和发行，不是44次实机操作。
C-3的51格是17份catalog×3语，不是51次启动或17个插件。
目录内按显示键和消费者列子项；代表格不等于全部键覆盖。
本技能负责macOS显示方法；其他主账只安排交接，不借显示结果关闭。
读当前总账和已有证据，只取本轮受影响的未完成项。
技能不保存动态完成数或第二份待办。

## 一张批次表

默认使用最新已验成功的完整底座，只叠加本批工具与测试。
不得为单测移除已修功能。
未注入的原厂实例只作独立对照，标明未注入；不抵候选回归。

按`语言组合 + 候选/资源 + 场景 + 启动方式/初始状态`合并。
分别记录Cavalry语言和Switcher界面语言；两者不必相同。
同语言不够：不同候选、场景输入或helper/正常启动不能混用证据。
正常启动已能继续操作时，首帧采完就沿用该进程做稳定显示。
证据分账不要求另起进程；仅正常路径无法继续时另开获准helper。
只为正常首帧批次约束启动方式；普通显示不额外要求登录。
每行只写批次条件、总账子项、脚本/场景、动作顺序和恢复动作。
启动前一次装齐必要测试组件，不装未用的诊断库。
保留驱动源、固定请求、构建入口和运行方法，下次直接复用。
缺驱动先查私人历史；未找到则记缺口，不编造脚本路径。

## 一个语言批次的顺序

1. 本批若测正常首帧，先采首次可见文字，不先开菜单或刷新。
2. 证明场景实际加载。复用同版本输入证明时，仍核当前名称与行数。
3. 核静态标签、空提示、名称和tab，再切枚举并恢复默认值。
4. 连续读属性提示、节点说明和脚本帮助，各核实际popup。
5. 做搜索并清空；先保存查询读回，再恢复视图、FPS等状态。
6. 本语首帧及兼容显示都完成后，再切下一语；编辑链路用独立副本。

同语同场景的Timeline、Viewport、质量、固定帮助和FPS可连续完成。
属性与帮助若状态兼容也并入，不为单项反复切三语。
不同场景在同语言批次内切换，不为每个场景重切语言。
不要先轮完三语首帧，再轮三语稳定显示，造成第二遍切语。
新驱动未加载时留到下一次必要会话，不为合批重跑已过项。
重开、English Restore和故障注入改变前置状态，先封存当前批结果。
Restore是独立产品事务，不用实验回滚冒充；普通Switch不二次确认。
失败只补受影响项；字体候选改变仍回归完整适用矩阵。
